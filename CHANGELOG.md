# Changelog

Each entry lists breaking changes first. Railway shows deployers an "update available" notice when `main` changes; read the entry before applying it.

## 2.19-railway.1 (2026-11-24)

First release of the template.

- selfoss **2.19** (latest stable release, 2022-10-12), built from the official release zip `selfoss-2.19.zip` (sha256 `e49c4750e9723277963ca699b602f09f9148e2b9f258fce6b14429498af0e4fc`). Upstream publishes no Docker image.
- Base image `php:8.2.36-apache-bookworm@sha256:bc98ca50e86358fc4f7c37b179a7edfacd6164663d3167925f0a0a85def09054`, with GD (JPEG, WebP, FreeType) for favicons and thumbnails.
- SQLite database, favicons, thumbnails and sessions on the Railway volume at `/var/www/html/data`.
- The login is always on: user `SELFOSS_USERNAME` (default `admin`), password `SELFOSS_ADMIN_PASSWORD` (generated by the template, hashed at start). The service refuses to start without a password.
- Works around upstream advisory GHSA-2v57-rcgq-j44q (boolean options set to `false`/`off`/`no` were read as true) by normalising every boolean `SELFOSS_*` variable to `0`/`1`.
- Built-in feed updater runs `cliupdate.php` every `SELFOSS_UPDATE_INTERVAL_MINUTES` (default 30), one run at a time.
- Apache workers and PHP memory are sized from the container's memory and CPU limits, so it fits Railway's 0.5 GB plan.
- Health check `/api/about`; the container exits non-zero if Apache stops, so Railway restarts it.
